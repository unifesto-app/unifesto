# WeGoBeyond (wegobeyond.in)

Next.js 16 + Tailwind 4. Content and crew sign-ups come from the Unifesto API; admin is in Unifesto Apex.

This site lives in the Unifesto monorepo at `websites/wegobeyond` and ships with `./deploy.sh wegobeyond` (or a full deploy).

```bash
npm install
npm run dev
```
