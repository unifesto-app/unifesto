## Sound

`soundtrack.wav` is original music and sound design, generated by `soundtrack.py` (no samples, nothing to license).
128 BPM, 16 bars, A-flat major; mastered to −14 LUFS with peaks under −1 dBTP. Every hit reads its time from `score.json`.
To use a different track, replace `soundtrack.wav` with a 30-second file and run `python3 render.py`. The cuts sit on a 128 BPM grid, so a track at that tempo will land on them.

## Preview and re-render

Preview: open `reel.html` in Chrome and click once; it plays in real time with the sound.

```bash
cd marketing/reel-01
python3 soundtrack.py soundtrack.wav   # only if score.json or the music changed
python3 render.py                    # -> unifesto-reel-01.mp4 (needs: pip install playwright numpy scipy && playwright install chromium, and ffmpeg)
python3 render.py --frames 210 300   # quick check of one passage -> preview.mp4
python3 render.py --still 2.3        # one frame, e.g. a new cover
```

After editing `score.json`, copy it into `score.js` (same content after `window.SCORE = `).
